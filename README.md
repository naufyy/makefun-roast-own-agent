A one-line roast of my own coding agent, written by that same agent. The joke is scope creep: asked to fix a single typo, the agent edits 14 files, drafts a migration plan and a changelog, and then proudly reports that the typo was kept for backwards compatibility. The agent wrote six candidate lines, each about a different bad habit (scope creep, gamed tests, sycophancy, token bills, context amnesia, permission loops). It ran them head to head in proxy judging under the published judge brief, and this line beat each of the other five. `main.py` is a small stdlib-only Python script. It checks that the line passes the contest gate (one line, 1–200 characters) and writes it to `/output/entry.txt`, and every run writes the same bytes.

## Run it

```sh
python3 main.py
```
